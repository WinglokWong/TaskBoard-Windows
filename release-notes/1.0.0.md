The first Windows release of TaskBoard: a lightweight, offline kanban board inspired by Trello. It matches [TaskBoard for macOS 1.4.2](https://github.com/WinglokWong/TaskBoard/releases/tag/v1.4.2) and uses the same data format, so `.taskboard` files move freely between Mac and Windows.

## Features
- **Boards, lists and cards**: Markdown descriptions, labels, checklists, colors, attachments (with cover images) and an archive.
- **Drag and drop**:
  - An exact copy of the card or list follows the pointer, and the others make room.
  - On release the copy glides into place; Esc cancels.
  - The board scrolls automatically near the edges.
- **Due dates and reminders**:
  - Windows notifications at the due time or 15 minutes, 1 hour or 1 day before.
  - A Due Soon view collects due cards from every board.
- **Filters and search**: filter by label, status or due date, combined with search.
- **Keyboard and undo**: keyboard shortcuts throughout (Ctrl+/ lists them), and Ctrl+Z / Ctrl+Y undo and redo for everything.
- **Your data stays safe**:
  - A daily automatic backup, restorable at any time.
  - Export a board or all data (attachments included) and import it on another PC or Mac.
- **Three languages**: English, Simplified Chinese and Traditional Chinese, switchable instantly in Settings.
- **Windows 11 look**: Mica, native menus and dialogs, your accent color, and light and dark mode.
- **Automatic updates**: future versions download in the background; restart when prompted to install.

## Install
1. Download **TaskBoard-Setup-1.0.0.exe** below and run it.
2. The installer isn't code-signed, so Windows SmartScreen may show "Windows protected your PC". Click **More info → Run anyway**. This is only needed once; later versions arrive through the in-app updater.

Installs per user, so no administrator rights are needed. Requires Windows 10 or 11 (64-bit).

## Coming from the Mac
On the Mac, choose **File → Export All Data…**, copy the `.taskboard` file to your PC, and double-click it. Then choose **Replace All Data** or **Add as New Boards**.
